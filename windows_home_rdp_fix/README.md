# Windows 家庭版 RDP 修复

家庭版（Core\*）没有远程桌面主机功能，Child Session 方案在家庭版上不可用。本工具用系统自带的 `changepk.exe` 把家庭版切换到专业版，从而补齐 RDP 主机。

## 用法

1. 双击 `修复家庭版RDP.bat`，会请求管理员权限。
2. 输入你自己的**正版 Windows 专业版密钥**，等待升级完成。
   也可以在脚本同目录放一个 `key.txt`（第一行是密钥），脚本会直接读它，不再询问。
3. 重启电脑。重启后运行 `修复家庭版RDP.bat /check` 确认版本已切换。

/check 只读取当前版本，不修改系统；版本不是家庭版时直接退出，不会请求提权。

## 边界

- 只做版本切换，不做激活、HWID/KMS 之类的事情。密钥必须有效，切换后系统需要正常激活。
- 不内置任何密钥，也不复制 Microsoft-Activation-Scripts 的实现。
- 升级前请备份并保存工作，切换过程不可逆（除重装外）。
- 等价的手动操作：`设置 > 系统 > 激活 > 更改产品密钥`。
